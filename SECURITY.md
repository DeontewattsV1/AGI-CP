# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Default branch: AGI-CP v0.2 errata and the reference capability gateway | Yes |
| AGI-CP v0.1 invariants I7 and I8 | No |

v0.1 invariants I7 and I8 are retired. The v0.2 errata is the supported protocol text. Fixes land on the default branch.

## Reporting a vulnerability

Report suspected vulnerabilities to **deonte@goodshyt.fun**. Include the affected path, what you expected the gate to do, and a reproduction if you have one. Do not open a public issue for a vulnerability that is not yet fixed.

You should receive an acknowledgement within 7 days. The maintainers will coordinate a fix and a disclosure window with you.

A report about the protocol is not a claim that this repository contains arbitrary AGI. AGI-CP is a fail-closed capability-authorization standard and a reference gateway.
